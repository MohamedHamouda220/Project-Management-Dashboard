# 📊 Project Management Dashboard | Power BI

## 📌 Overview

This project is an interactive **Project Management Dashboard** built using **Microsoft Power BI**. It provides a high-level overview of project performance, task distribution, project hours, and headquarters locations through interactive visualizations and filters.

---

## 🎯 Objectives

- Monitor project performance.
- Track total projects, tasks, and project hours.
- Analyze task priorities.
- Visualize project distribution across headquarters.
- Explore project trends over time.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

---

## 📈 Dashboard Features

- KPI Cards
  - Total Projects
  - Total Tasks
  - Total Project Hours

- Interactive Filters
  - Date Range
  - Location

- Visualizations
  - Project Tasks by Priority
  - Project Distribution by Headquarters (Map)
  - Project Distribution by Month

- Interactive Navigation
  - Multi-page Report
  - Drill Through (if implemented)

---

## 📂 Dataset

The dashboard uses a project management dataset containing information such as:

- Project Name
- Task ID
- Department
- Location
- Start Date
- End Date
- Priority
- Project Hours
